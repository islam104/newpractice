# Practica

Проект состоит из Windows-службы `practica_service.exe` и GUI-клиента `practica.exe`.

## Что реализовано

### Windows-служба

- после успешной активации служба загружает антивирусные базы в память;
- базы хранятся в `std::map<uint64_t, std::vector<AvRecord>>`, где ключом выступают первые 8 байтов сигнатуры;
- запись базы содержит:
  - `ObjectSignaturePrefix`;
  - `ObjectSignatureLength`;
  - `ObjectSignature` (SHA-256 от полной сигнатуры);
  - `OffsetBegin`;
  - `OffsetEnd`;
  - `ObjectType` (`PE` и `PowerShell Script`);
  - `AvRecordSignature` (SHA-256 от сериализованных полей записи);
- движок сканирования работает поверх абстракции потока байтов и проверяет:
  - тип объекта;
  - диапазон смещения;
  - дополнительные байты сигнатуры;
  - хэш полной сигнатуры;
- поддержано сканирование:
  - выбранного файла;
  - выбранной директории;
  - всех несъёмных дисков;
  - по расписанию;
  - при мониторинге выбранных директорий;
- зарегистрированы RPC-методы для:
  - аутентификации и активации;
  - получения информации о базах;
  - сканирования файла;
  - сканирования директории;
  - сканирования всех несъёмных дисков;
  - настройки расписания;
  - настройки мониторинга директорий;
  - получения последнего фонового результата сканирования.

### Графическое приложение

- показывает дату выпуска антивирусных баз и количество записей;
- умеет запускать сканирование файла;
- умеет запускать сканирование папки;
- умеет запускать сканирование всех несъёмных дисков;
- умеет настраивать сканирование по расписанию;
- умеет настраивать мониторинг директорий;
- показывает результаты ручного и фонового сканирования.

## Демонстрационные сигнатуры

Встроенные базы содержат демонстрационные сигнатуры для:

- `PE`: `Demo.PE.Injector`, `Demo.PE.Dropper`;
- `PowerShell`: `Demo.PS.Downloader`, `Demo.PS.Obfuscated`.

Это позволяет быстро проверить сканер на тестовых файлах без внешнего сервера баз.
